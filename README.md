## 📊 3. МАТЕМАТИЧЕСКАЯ МОДЕЛЬ И ЭКОНОМИКА

### А. Формула обслуживания с частичной информацией (Partial Info)
Гость показывает **2 из 3 характеристик**. Скрытая третья — всегда худшая (вес 0.5). Из видимых одна имеет вес 1.5, вторая 1.0.

$$M = \frac{1.5 \cdot S_{\text{primary}} + 1.0 \cdot S_{\text{secondary}} + 0.5 \cdot S_{\text{hidden}}}{100}$$

* **Циклический ростер специалистов:**
  * **YUKI (SSR):** Talk 90 / Charisma 35 / Service 10 $\implies$ $M \in [0.95 .. 1.75]$
  * **MIRA (SR):** Talk 10 / Charisma 90 / Service 35 $\implies$ $M \in [0.95 .. 1.75]$
  * **SAKURA (SR):** Talk 35 / Charisma 10 / Service 90 $\implies$ $M \in [0.95 .. 1.75]$
  * **NIKA (R, ¥120k):** 50 / 50 / 50 $\implies$ Универсал (всегда $M = 1.50$)
  * **LUNA (SSR, ¥300k):** 85 / 85 / 85 $\implies$ Лейтгейм-трофей ($M = 2.55$)
* **Бейджи фидбека:** $M \ge 1.7 \implies$ 🔥 `PERFECT MATCH`; $1.0 \le M < 1.7 \implies$ ✨ `GOOD`; $M < 1.0 \implies$ 💢 `POOR`.
* **Штраф усталости:** Хостес в статусе `TIRED` получает множитель $M_{\text{final}} = M \times 0.8$.

## 🏛️ 6. АРХИТЕКТУРА ХРАНЕНИЯ (REDIS 7 + POSTGRESQL 15)

В проекте реализована схема **Consumer-Driven REST Sync** с разделением на горячий оперативный слой и финансовый сейф:
[ BROWSER: React 19 + TypeScript ]
Хранит в localStorage ТОЛЬКО guest_id (UUIDv4)
Вычисляет 60 FPS UI-стриминг
│
├──► POST /api/shift/start
│ └── HSET session:{guest_id} (Redis TTL 600s) + lock:shift:{guest_id} (tab_id takeover)
│
├──► POST /api/shift/action (ASSIGN / PLACATE / GUEST_LEFT)
│ └── FastAPI валидирует стамину и обновляет snapshot столов в Redis
│
├──► GET /api/shift/state (F5 Reconnect)
│ └── Мгновенное восстановление смены из оперативной памяти Redis
│
└──► POST /api/shift/complete
└── 1. Серверный античит: проверка времени [285..330s] и Санити-капа (8.2M gross / 1.2M tips).
└── 2. Атомарная транзакция в PostgreSQL:
INSERT INTO shift_history (...) ON CONFLICT (shift_id) DO NOTHING;
UPDATE users SET yen = yen + :net_yen;
UPDATE user_hostesses SET stamina = ... + 20 (сон);
└── 3. DEL session:{guest_id} (Очистка памяти).
