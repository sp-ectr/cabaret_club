# CABARET TYCOON

Мини-игра **crisis-management tycoon** (Web): вы — управляющий
ночным кабаре-клубом в стиле Yakuza 0. Проводите 5-минутные смены, обслуживайте
гостей трёх классов (голяк / средняк / богач), управляйте выносливостью хостес и
делите прибыль между персоналом, безопасностью и развитием клуба — от ★1
подпольного бара до ★★★ дворца Камурочо.

Мем-якорь: Мадзима с арбузом («я принёс вам вкусненькое в трудные времена») —
интро игры, и событие «Baka Mitai» посреди смены.

## Стек

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4, Zustand, Vitest
- **Backend (в разработке):** Python, FastAPI, Redis (сессии смен), PostgreSQL (перманентный прогресс)
- **Архитектура:** Action-Driven REST Sync — клиент симулирует смену локально,
  сервер хранит правду о сессии (F5 ничего не теряет), прогресс — в PostgreSQL

## Структура

```
docs/MANIFEST.md   — полные правила и баланс игры (единый источник правды)
docs/API.md        — контракт REST API между фронтом и бэкендом
frontend/          — игра (React + TS)
cabaret_club/      — Python-пакет бэкенда
```

## Запуск (фронтенд)

```bash
cd frontend
npm install
npm run dev
```

Тесты: `npm test` (Vitest).

Полное описание механик, экономики и условий победы — в [docs/MANIFEST.md](docs/MANIFEST.md).
